# Windows 설치와 첫 실행

이 문서는 개발 후보를 위한 안내입니다. Windows 11·Python 3.12에서 격리 가상환경을 이용한 부분 시험이 이뤄졌지만 모든 Windows 환경에서의 설치를 보증하지 않습니다. 설치 시 Python 패키지를 인터넷에서 내려받습니다.

1. GitHub에서 저장소를 내려받아 압축을 풀거나 복제합니다. 현재 저장소는 비공개이므로 접근 권한이 필요합니다.
2. Python 3.12와 Python launcher를 설치하고 PowerShell에서 `py -3.12 --version`을 확인합니다.
3. 압축을 푼 폴더를 PowerShell에서 열고 아래 명령을 순서대로 실행합니다.

```powershell
.\scripts\doctor.ps1
.\scripts\install.ps1
.\.venv\Scripts\python.exe .\scripts\smoke_test.py
.\scripts\start.ps1
```

스모크 테스트는 일회용 합성 PDF와 빈 DB로 실행합니다. `core`의 `PASS`만 기본 문자 기능의 간단한 시험 통과를 뜻합니다. 모델 시험을 실행하지 않았다면 `embedding`과 `reranker`는 `NOT_RUN`입니다.

설치기는 이 프로젝트가 만든 것으로 표시된 `.venv`만 재사용합니다. 표식이 없는 기존 `.venv`나 연결된 경로는 덮어쓰지 않고 중단하므로, 기존 파일을 확인한 뒤 새 빈 설치 폴더를 사용하세요. Windows Python 3.12용 패키지 버전은 `requirements-windows-base.lock`에 고정되어 있습니다. 패키지 파일 자체의 해시 고정은 아직 제공하지 않습니다.

4. 브라우저의 `http://127.0.0.1:18531`에서 문헌 0건을 확인합니다. `문헌 관리`에서 본인이 사용 권한을 가진 PDF와 제목을 입력하고 등록합니다.
5. `문헌 검색`에 문서에 포함된 문자를 입력합니다. 페이지를 확인하려면 `문헌 관리`에서 원본 PDF를 내려받아 해당 쪽을 엽니다. `원고 검사`의 결과는 자동 판정이 아니며 사람이 확인해야 합니다.
6. 종료하려면 실행 중인 PowerShell에서 Ctrl+C를 누릅니다. 데이터와 보고서는 기본적으로 사용자 홈의 `ArticleAI-data/documents.sqlite3`에 저장됩니다. 백업은 앱을 완전히 종료한 후 이 파일을 별도 위치에 복사합니다.

의미 검색은 별도 설치가 필요합니다. [CPU 의미 검색 안내](SEMANTIC_SEARCH.md)와 [모델 다운로드 안내](MODEL_ARTIFACTS.md)의 크기·라이선스·한계를 먼저 확인하세요. 모델이 없어도 현재 문자 검색은 작동하지만 이는 정식 AI 프로필이 완료됐다는 뜻이 아닙니다.

설치가 실패하면 Python 3.12, 인터넷, 디스크 여유 공간과 PowerShell 오류를 확인합니다. 스크립트 실행이 정책상 차단되면 조직이나 PC의 정책을 확인하세요. 포트가 이미 사용 중이면 기존 서비스를 종료하지 말고 충돌 원인을 확인합니다. OCR이 없으므로 스캔 PDF는 텍스트가 추출되지 않을 수 있습니다. 설치 폴더와 데이터 폴더 삭제는 등록 문헌을 삭제하므로 필요한 백업을 먼저 보관하세요.
