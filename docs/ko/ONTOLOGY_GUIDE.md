# 개념 관리 — 초기 버전

이 기능은 사용자가 직접 작성한 **개념 사전과 문헌 연결**입니다. 원본 제품의 문헌 종류 분류 체계와는 별개이며, 기존 온톨로지를 복원했다고 주장하지 않습니다. 스키마 버전은 1이고 처음에는 개념과 연결이 0건입니다.

`개념 관리`에서 개념을 추가하고 제목을 변경할 수 있습니다. 개념 안에서 등록된 문헌을 선택해 연결하거나 연결을 해제합니다. 비활성화된 개념과 기존 연결은 보존되며 다시 활성화할 수 있습니다. 이름은 유니코드 정규화, 공백 정리, 대소문자 정규화를 거쳐 중복을 제한합니다. 변경 이력에는 문헌의 SHA-256이 기록되고 최근 100건을 화면에서 볼 수 있습니다. 사용자가 입력한 개념과 이력은 개인 데이터이므로 DB와 함께 보호하세요.

문헌 삭제 시 해당 연결은 함께 삭제되고 삭제 이력이 저장됩니다. 자동 AI 관계 생성, 지지·반박 확정, 개념 병합·동의어, 가져오기/내보내기, 관계 그래프와 검색 품질 회귀 검사는 아직 없습니다. 이 기능만으로 의미상 타당성이나 근거가 검증되지는 않습니다.

## 백업과 복원

앱을 종료한 상태에서 README에 적힌 데이터베이스를 별도 위치에 복사합니다. 복원 전 앱을 종료하고 현재 DB를 먼저 보관한 다음, 사용자가 선택한 백업을 DB 위치에 복사합니다. 이 작업은 현재 데이터를 덮어쓰므로 신중히 수행하세요. SQLite 백업 API로 생성한 복사본의 무결성과 연결 복원은 자동 테스트에서 확인했습니다. 사용자 PC의 백업은 별도로 확인해야 합니다.

새 빈 DB 또는 이전 후보 DB에 v1 테이블을 생성합니다. 더 높은 스키마 버전은 변경하지 않고 시작을 중단합니다. v1 이후의 스키마 마이그레이션과 다운그레이드는 아직 제공하지 않습니다. 업그레이드 전 백업이 필요합니다.
