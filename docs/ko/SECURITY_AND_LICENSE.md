# 보안·개인정보와 라이선스

앱은 기본적으로 `127.0.0.1`에만 바인딩하지만 자체 사용자 인증을 제공하지 않습니다. 같은 컴퓨터의 다른 사용자·프로세스가 접근할 수 있는 환경이라면 OS 계정과 파일 권한으로 데이터를 보호하세요. PDF, 텍스트, 보고서, 개념과 실험 색인은 사용자의 DB에 저장됩니다. 백업 파일도 같은 수준으로 보호해야 합니다.

패키지 설치 시 Python 패키지 배포처에 접속하며, 사용자가 명시적으로 모델 다운로드를 실행하면 해당 모델의 공식 배포처에 접속합니다. 현재 구현에는 사용자 문헌을 외부 LLM에 보내는 기능이 없습니다. 악성 PDF에 대한 완전한 격리 처리는 아직 제공하지 않으므로 신뢰할 수 없는 파일을 주의해 다뤄야 합니다.

이 저장소의 코드·문서는 [Apache-2.0](../../LICENSE)입니다. 사용자가 등록하는 PDF는 여기에 포함되지 않으며 그 권리는 각 권리자에게 있습니다. 다운로드하는 모델과 Python 의존성은 각각의 라이선스와 고지 조건을 확인해야 합니다. 코드 라이선스가 문헌이나 모델의 사용 권한을 부여하지 않습니다. 모델별 공식 카드와 버전은 [모델 안내](MODEL_ARTIFACTS.md)에 있습니다.

공개 후보의 파일은 `PUBLIC_FILES.txt`로 제한하고 Git 이력에 포함된 큰 파일·일부 비밀정보 패턴을 검사합니다. 이력에 개인 이메일이 남지 않도록 이 저장소의 검사는 커밋의 작성자·커미터 이메일을 GitHub no-reply 주소로 제한합니다. CI는 고정된 Windows 의존성 목록에 대해 알려진 취약점도 조회합니다. 검사는 오류나 새로운 취약점을 모두 찾아낸다는 보장이 없고, 모델·문헌의 권리나 원본 제품과의 기능 동등성을 판단하지 않습니다.
